How saving works

There is no server behind this site. Every edit is stored in this browser and applied to the live portfolio immediately, so you can review it at once. To make a change permanent for visitors, download the file below and replace src/app/core/data/content.json in the repo, then redeploy.

The same file is also copied to the site root at build time, so you can edit content.json on the deployed host to change the site without rebuilding.
